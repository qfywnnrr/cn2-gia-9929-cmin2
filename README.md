## 三网优化优化的到底是哪一段

三网优化指电信、联通、移动三家用户访问这台服务器时，回程各走各的精品链路。三条线分别对应：CN2 GIA 是中国电信的 AS4809，走独立 MPLS 标签交换路径，不和 163 普通流量抢国际出口；AS9929 是联通的精品商业网，业内叫 CUII，定位对标 CN2 GIA；CMIN2 是 AS58807，移动新一代国际精品网，比老的 CMI 线路在延迟和稳定性上有提升。三家运营商、三条 AS 号，缺一条就不该叫三网优化。

值得展开的是“优化的是回程”。从你本地到机房这一段由本地运营商决定，商家真正能控制的是从机房回中国的方向。测一台机器是不是真优化，只看回程路由里中国段的 AS 号，去程绕不绕路意义有限。

## 怎么验证一台 VPS 是不是真三网

先看官方页面有没有逐条写出回程 AS 号。只写“三网优化”“CN2 线路”“大陆直连”而不给具体 AS 号的，基本可以当成营销话术；写了 CN2 GIA、AS9929、CMIN2 三个具体名称，才值得往下查。

再拿测试 IP 做 traceroute。在晚高峰 20:00–23:00 跑一次，回程看进入中国后的第一跳或第二跳：出现 202.97.x.x 是 163 普通骨干，59.43.x.x 是 CN2，218.105.x.x 或 210.51.x.x 是 9929，223.120.x.x 是 CMI/CMIN2。三条路径各自落到不同 AS，才算真三网。

第三步是排除国际线路产品。LightLayer 的菲律宾产品里有一个 MANILA-GLOBAL NETWORK 系列，第三方 traceroute 记录显示：从马尼拉经香港、NTT 到美国圣何塞，再回中国电信 4134，广州落地 240ms 左右。这条路径绕了半个太平洋，属于典型的国际线路。同一家机房往往同时卖国际线路和优化线路，名字里带 GLOBAL、International、T1 的，基本不属于三网优化。有些商家的香港国际线路产品，电信联通去程绕日本甚至美国，实际延迟比洛杉矶优化款还高。机房近不等于线路近。

## 常见问题

**晚高峰会不会掉速？**
第三方对香港款的评级是 E4-尚可，原话是“整体网络质量一般”，建议观察晚高峰数据；美国款的测评里出现过联通 9929 家宽延迟 234ms、丢包约 30% 的单次记录。这些都是单次测试，不能当长期结论。自己拿测试 IP 在 20:00–23:00 跑 ping 和 traceroute，比看任何测评都准。

**流量超了会怎样？**
公开资料没有写超流量后的处理方式，是降速还是停机需要下单前确认。标 1T 双向的套餐，按单向 500G 规划更稳。

**IP 被墙、想换 IP 怎么办？**
换 IP 的费用和频率，公开资料里没有列明，购买前问清楚。

**能不能退款？**
退款窗口和流量上限同样没有公开写明。不确定就先月付，跑一两周再决定要不要年付。

**续费会不会涨？**
24.99 USD/年属于不定期补货的促销款，续费价未公开。按年付之前，先把续费价格确认下来。
